# TypeRoom · 字间

一个在本机运行的字体展示与对比工具。把字体放进指定文件夹，就能自动生成预览；后续添加字体，无需修改代码或手动维护清单。

![TypeRoom 字间：字体库、预览文字和字号设置](docs/images/screenshot.png)

## 功能

- 自动扫描字体目录及子文件夹，每 3 秒同步新增、修改和移除的字体。
- 支持 TTF、OTF、WOFF、WOFF2，以及 Unity TextMeshPro（TMP）字体资源包。
- TMP 资源包根据文件头识别，支持没有后缀的文件，兼容新旧两种字符表格式。
- 中文、日文、英文、数字预设，以及自定义预览文字、字号和字间距。
- 搜索字体名称与文件名，按风格筛选，切换网格 / 列表视图。
- 收藏字体，最多同时对比 4 款，支持普通字体与 TMP 字体混合对比。
- TMP 预览直接使用包内字形，缺字显示方框，并列出缺少的字符。
- 查看字体详情，包括文件名、字重、大小，以及 TMP 的 Unity 版本、字符数量和图集尺寸。

截图中的字体来自本机目录，仓库中不附带字体文件。

## 快速开始

需要 **Python 3.10 或更新版本**。Windows 用户可以直接使用项目中的启动脚本。

1. 下载并解压本仓库，或运行：

   ```powershell
   git clone https://github.com/Furude-rika-mipa/TypeRoom.git
   cd TypeRoom
   ```

2. 双击 **`start.cmd`**。
3. 首次启动会自动生成 `settings.json`，并准备 TMP 预览依赖；首次安装依赖需要联网。
4. 浏览器自动打开后，将字体放入项目的 `fonts` 文件夹，或者在页面中点击“添加字体”、拖入字体文件。

默认地址是 `http://127.0.0.1:8765`。端口被占用时，程序会尝试后续端口，实际地址以启动窗口显示的为准。
使用时保持启动窗口打开；关闭窗口或按 `Ctrl+C` 即可停止服务。

### start 和 setup 有什么区别？

| 文件 | 用途 |
| --- | --- |
| `start.cmd` | 日常使用的入口：检查依赖、启动本地服务，并打开浏览器。 |
| `setup.cmd` | 手动安装或修复依赖；首次自动安装失败、换电脑或依赖出问题时使用。 |
| `launch.py` | Python 启动入口，也可运行 `python launch.py --open`。 |

依赖安装在项目内的 `.deps` 文件夹，不需要每天运行 `setup.cmd`。安装完成后，字体展示可以离线使用。

## 字体文件路径在哪里改？

修改 **项目根目录的 `settings.json`**，也就是和 `start.cmd` 放在一起的配置文件。
首次启动时，程序会从 [settings.example.json](settings.example.json) 自动生成这个文件；也可以自行复制一份并重命名为 `settings.json`。

找到 **`font_directory`**，改成自己的字体目录。例如，想读取 `D:\Fonts`：

```json
{
  "font_directory": "D:/Fonts",
  "port": 8765
}
```

**保存后，关闭原来的启动窗口，再双击 `start.cmd`，新路径就会生效。**

- 路径推荐使用正斜杠 `/`，例如 `D:/Fonts` 或 `F:/其他/字体文件`。
- 如果使用反斜杠，需要在 JSON 中写成双反斜杠，例如 `"D:\\Fonts"`。
- 也可以使用相对路径；默认的 `"./fonts"` 表示项目里的 `fonts` 文件夹。
- 字体目录支持子文件夹。日常新增、删除或替换字体时，页面会自动更新，无需重新启动。
- `port` 是本地服务的起始端口，一般保持 `8765` 即可。

`settings.json` 是本机配置，已被 Git 忽略；仓库提供的 `settings.example.json` 使用通用路径。

### 临时指定目录

不修改配置文件，也可以用命令行临时指定目录和端口：

```powershell
python launch.py --font-dir "D:\Fonts" --port 8765 --open
```

## 添加和预览字体

直接把字体放进配置好的文件夹，约 3 秒后会出现在页面中。移动或删除字体，也会自动同步。
通过页面添加的字体会复制到这个目录；遇到同名文件会自动改名，保护已有文件。

普通字体使用浏览器原生 `FontFace` API，按需加载，一次最多三款。
收藏、预览文字和显示设置保存在当前浏览器的 `localStorage` 中；按 `/` 可以快速搜索。
程序会自动忽略隐藏目录和 macOS 的 `._` 附带文件。

### TMP 字体

点击“**TMP 字体**”筛选，可以单独查看资源包。程序会读取包内的实际字体名称、字符表和图集；同一个包中包含多个字体时，会分别展示。

首次发现资源包时会后台解析，页面显示解析状态并自动更新。字符表、图集和预览结果会缓存，避免重复处理大图集。磁盘缓存位于 `.cache/tmp`；原始资源包只读，不会被改写。

TMP 预览支持文字修改、字号、字间距、换行和字体对比。未收录的字符显示方框，并在卡片中明确提示；例如，部分中文字体包可能没有包含日文假名。

## 说明与限制

- 所有字体读取和预览请求均由本机 `127.0.0.1` 服务处理，无需安装系统字体。
- 字体风格根据元数据和名称推断，个别分类可能不准确。
- WOFF2 可正常预览，名称默认使用文件名，字重按 400 显示。
- 普通字体缺字时，浏览器可能使用系统字体补足；TMP 预览会明确标出缺字。
- TMP 资源包需要包含字符表和所引用的图集；预览用于比较基础字形，不复刻游戏中的描边、阴影等材质效果或复杂文字整形。
- 超长 TMP 预览会截断并提示。TTC / OTC 字体集合暂不支持。

## 项目结构

```text
TypeRoom/
├─ dist/                   网页界面、样式和脚本
├─ docs/images/            README 截图
├─ fonts/                  默认字体目录
├─ tests/                  自动化测试
├─ server.py               本地 HTTP 服务与字体扫描
├─ tmp_fonts.py            TMP 资源解析、缓存和字形绘制
├─ launch.py               依赖检查与启动入口
├─ start.cmd               Windows 日常启动脚本
├─ setup.cmd               Windows 依赖安装脚本
├─ requirements.txt        Python 依赖
├─ settings.example.json   通用配置示例
└─ settings.json           首次运行生成的本机配置，不提交到 Git
```

## 技术栈与验证

前端使用 HTML、CSS、原生 JavaScript、FontFace 和 Canvas；后端使用 Python 标准库 HTTP 服务。
TMP 解析和绘制使用 UnityPy、Pillow。无需前端构建步骤。

安装依赖后，在项目根目录运行测试：

```powershell
python -m unittest discover -s tests -v
```
